# Élan — inventaire du domaine et de la couche données (référence de portage)

Source : `src/lib/**`, `src/hooks/**` (app Expo 1.9.0, schéma SQLite v7). Les constantes, seuils et formules ci-dessous doivent être reproduits **exactement** en Kotlin. Les tests Jest de `__tests__/lib/` sont la référence de comportement.

## 0. Règles structurantes
- Local-first, aucun backend, aucun compte. Seuls accès réseau, opt-in et désactivés par défaut : sauvegarde S3 auto-hébergée et fond de carte MapLibre. Import Strava = fichiers (jamais OAuth).
- Une seule connexion BLE cardio globale, idem capteur CSC.
- Séance : accumulation mémoire → à l'arrêt, écriture atomique → navigation `replace` vers le détail. `endedAt IS NULL` = en cours, exclu de l'historique et des stats.
- Commentaires et UI en français.

## 3. Filtre GPS (`gps-filter.ts`, classe `GpsConsolidator`)
Entrée `GpsFix { ts, lat, lon, altitude|null, accuracy|null, altitudeAccuracy|null, speed|null (m/s) }` → `{ point|null, deltaDistanceM, deltaElevationGainM }`, `ConsolidatedPoint { ts, lat, lon, altitude|null, speedKmh|null }`.
Constantes : `MAX_ACCURACY_M 50`, `MAX_PLAUSIBLE_SPEED_MS 30`, `STANDSTILL_SPEED_MS 0.7`, `DISTANCE_ANCHOR_M 5`, `KALMAN_MIN_PROCESS_NOISE_MS 3`, `ALTITUDE_WINDOW 7`, `ELEVATION_HYSTERESIS_M 5`, `MAX_ALTITUDE_ACCURACY_M 12`, `DEFAULT_ACCURACY_M 15`, `ALT_RESET_GAP_S 30`.
Pipeline : (1) `accuracy = max(fix.accuracy ?? 15, 1)`, > 50 → rejet ; (2) si `lastAccepted` : `dt=(ts-prev.ts)/1000`, `dt<=0` → rejet, `haversine/dt > 30` → rejet ; (3) Kalman 1D : premier fix `est=lat/lon, variance=acc²` ; sinon `dt=max(…,0.001)`, `q=max(3, speed??0)`, `variance += dt*q*q`, `gain=variance/(variance+acc²)`, `estLat += gain*(lat-estLat)`, `estLon = normalizeLon(estLon + gain*wrapLonDelta(lon-estLon))`, `variance *= 1-gain` (`wrapLonDelta` ramène dans [-180,180], `normalizeLon = ((((lon+180)%360)+360)%360)-180`) ; (4) si `lastTs>0 && (ts-lastTs)/1000 > 30` → `altWindow=[]` ; `lastTs=ts` ; (5) altitude lissée si `altitude != null && (altitudeAccuracy == null || <= 12)` : push, fenêtre 7, médiane ; (6) `speedKmh = speed>=0 ? speed*3.6 : null` ; (7) distance par ancre : pas d'ancre → ancre=point, delta 0 ; `moving = speed==null || speed>=0.7` ; `d=haversine(anchor,point)` ; `moving && d>=5` → delta = d entier, ancre avance ; (8) dénivelé hystérésis symétrique : `alt > anchor+5` → delta = alt-anchor, ancre=alt ; `alt < anchor-5` → ancre=alt, delta 0 ; (9) `lastAccepted=point`.

## 5. Temps en mouvement (`moving-time.ts`)
`MOVING_THRESHOLD_MS 0.7`, `MIN_SEGMENT_M 4`, `MAX_SEGMENT_SEC 30`. `< 2` points → 0. Par segment : `dt<=0` skip ; si `speedKmh != null` → `moving = speedKmh/3.6 >= 0.7` sinon `d=haversine`, `moving = d>=4 && d/dt>=0.7` ; `sec += min(dt,30)` ; `round`. À l'enregistrement : `moving = min(movingTimeSec, durationSec)`, `effectiveSec = moving>0 ? moving : durationSec`, `avgSpeedKmh = distanceM/1000/(effectiveSec/3600)`, stocké `movingTimeSec = moving>0 ? moving : null`.

## 6. Calories et zones (`calories.ts`)
`DEFAULT_MAX_HR 190`, `MUSCU_MET 4.5`. Tables (km/h → MET, interpolation linéaire, extrapolation plate) : vélo `[10,3.5][16,4.0][19,6.8][22.5,8.0][25.5,10.0][30.5,12.0][33,15.8]` ; course `[6.4,6.0][8.0,8.3][9.7,9.8][11.3,11.0][12.9,11.8][14.5,12.8][16.1,14.5][17.7,16.0]` ; marche `[3.2,2.8][4.0,3.0][4.8,3.5][5.6,4.3][6.4,5.0][7.2,7.0][8.0,8.3]`. Vitesses de repli : vélo 18, course 10, marche 5.
`estimateCalories({type, weightKg, durationSec, avgSpeedKmh?, elevationGainM?, avgHr?, maxHr?})` : `hours<=0 || weightKg<=0 → 0` ; `met` (muscu 4.5) ; `metKcal = met*weightKg*hours` ; si `avgHr>0 && maxHr>0` : `pct=clamp(avgHr/maxHr,0.4,1.05)`, `hrKcalMin = 0.082*weightKg*pct^1.7`, `hrKcal = hrKcalMin*durationSec/60`, `base = 0.4*metKcal + 0.6*hrKcal` sinon `base = metKcal` ; `elevBonus = muscu ? 0 : gain<=0 ? 0 : weightKg*0.011*gain` ; retour `base+elevBonus`.
`heartRateZone(hr, maxHr)` : `pct<0.6→1, <0.7→2, <0.8→3, <0.9→4, sinon 5`. Labels : Récupération, Endurance, Aérobie, Seuil, Maximal.

## 9. Géo, projection, cartes statiques
- `haversineMeters` R=6 371 000, `2R·asin(min(1,√h))`. `decimateByDistance(points, minM)` : ≤2 → tel quel ; premier/dernier toujours gardés ; intermédiaire gardé si `haversine(last,p) >= minM`.
- `createProjection(points, {width, height, pad=40})` : `latRange/lonRange = max(1e-6,…)`, `lonScale = cos(midLat)`, `scale = min((w-2p)/(lonRange*lonScale), (h-2p)/latRange)`, centrage, `project = [offX + (lon-minLon)*lonScale*scale, offY + (maxLat-lat)*scale]`, `metersPerUnit = 111320/scale`.
- `static-map.ts` : Web Mercator TILE 512, `lonToWorldX=(lon+180)/360`, `latToWorldY=0.5-ln((1+sinφ)/(1-sinφ))/(4π)`, zoom `clamp(log2(worldSize/512),0,20)` ; `null` si <2 points ou pas de style.

## 14. Conseil et progression automatique (`progression-advice.ts`, `auto-progression.ts`)
- `difficultyScore facile1/moyen2/dur3`. `suggestProgression(recent, window=3)` : filtrer non notés (aucun → maintiens) ; `lastN = derniers window` ; `last===3 → reduis` ; `last===1 && !lastN.includes(3) → augmente` ; `avg<=1.5 → augmente` ; `avg>=2.5 → reduis` ; sinon maintiens. - Texte : `fmtKg` (entier ou 1 décimale virgule) ; `describeChange` « {ex} {from} → {to} kg|s » ; `changeSummaryLine` « N exercice(s) renforcé(s) · M allégé(s) » ; `notificationContent` titres « Ton programme monte d'un cran » / « On lève le pied cette semaine » / « Ton programme évolue cette semaine », corps 3 premiers + « , +N » + « . ». ## 26. Points d'attention
1. `endedAt IS NULL` exclu partout (liste, stats, records, muscu). 2. Temps en mouvement plutôt que durée (`COALESCE(movingTimeSec, durationSec)`). 3. Trois seuils d'arrêt (0.7 filtre/moving, 0.8 agrégat) et trois plafonds de vitesse (30 m/s, 120 km/h, 160 km/h) volontaires. 4. Idempotence : finalizeSession, insertImportedSession, applyNotifications, progression hebdo, Health Connect. 5. Atomicité des écritures composites. 6. Best-effort strict pour backup auto, HC, récupération, notifications, snapshot carte, haptique, son. 7. HTTPS obligatoire (S3, style de carte), `map_style_url` jamais restaurée, secrets hors snapshot, XML durci, garde zip-bomb.
