# Élan — inventaire de l'interface, de la navigation et de la configuration native (référence de portage)

Source : `src/app/**`, `src/components/**`, `src/hooks/**`, `src/constants/theme.ts`, `DESIGN.md`, `app.json`, `plugins/*.js` (app Expo 1.9.0). Tout le texte UI est en français.

## 1. Navigation
Racine : `HeartRateProvider` → `CadenceSpeedProvider` → `BackupProvider` → Stack. Onglets `(tabs)` : Accueil (`view-dashboard-outline`), Historique (`history`), Réglages (`cog-outline`) ; barre `backgroundElement`, bordure `hairline`, labels 12/700. Routes : `sortie` et `muscu` en plein écran modal (fade) ; `session/[id]` (titre = activité) ; `session/map` plein écran ; `progression`, `poids`, `exercise/[name]` (« Progression »), `exercises` (« Catalogue d'exercices »).
Effets au démarrage (une fois) : `applyNotifications()`, `clearLiveSessionNotification()`, `recoverOrphanSessions()`, `reconcileOrphanGpsTask()`, `runWeeklyProgressionIfDue(now)`. Tap sur notification : `data.route` `/muscu` ou `/progression` → navigation ; jamais `/sortie` (créerait une nouvelle sortie). Handler global : pas de bannière, pas de son, pas de badge. `ErrorBoundary` plein écran (« Une erreur est survenue », « Réessayer »).

## 2. Écrans
### Accueil
Charge (au focus) : `statsSince(weekStart)`, `statsBetween(prevWeekStart, weekStart)` (prev = re-floor de `weekStart − 12 h`), `dailyDurations(7)` → 7 barres (aujourd'hui à droite), `listSessions(3)`, `hasMuscuDraft()`.
Ordre : en-tête « Bonjour 👋 » / « Élan » + `HrBadge` ; `PlanUpdateBanner` ; `TodayCard` (planning du jour : repos → `sleep` « Repos » « Récupération — pas de séance prévue » ; sinon pastille d'icône 46×46 teintée `color+'22'`, jour, label, exercices du template joints par « · » ou « Récup active / cardio », « Dernière séance {relatif} », bouton « Démarrer la séance » / « Reprendre ») ; « DÉMARRER UNE SÉANCE » grille 2×2 de boutons dégradés Vélo/Muscu (ou Reprendre)/Course/Marche ; carte lien → catalogue ; « CETTE SEMAINE » (4 `StatTile` compacts Séances `calendar-check`, Durée `clock-outline`, Distance `map-marker-distance`, Calories `fire` warning, avec tendance vs semaine dernière `+`/`−`, légende « vs sem. dernière ») ; `GoalsProgressCard` ; « ACTIVITÉ (7 DERNIERS JOURS) » `BarChart` accent ; « Récent » + « Tout voir » ; 3 lignes récentes ou `EmptyState` `run-fast` « Ta première séance t'attend ». Onboarding : `OnboardingSheet` si `onboarding_done` absent (pré-rempli du profil ; `onDone` → `saveProfile` + `onboarding_done='1'` ; `onRestore` → `RestoreSheet`, succès → alerte « Restauration terminée — N séance(s) restaurée(s) »).
### Historique
`FlatList`, `PAGE_SIZE 50`, `onEndReachedThreshold 0.5`. État : filtre type (`all` | activité), plage (`7|30|90|all`), recherche debounce 200 ms, compteur de run pour ignorer les réponses obsolètes. En-tête : titre, carte lien → `/progression` (« Progression muscu · Suivi des charges par exercice », `chart-line`), champ pilule (h 44, `magnify`, `close-circle`), chips types (« Tout » + libellés courts teintés), chips plages (7 j / 30 j / 90 j / Tout). Lignes `SessionRow`, séparateur 10. Vide filtré « Aucun résultat » ; vide absolu « Ton historique est vide » + action « Importer depuis Strava » (`file-import-outline`) → réglages, icône `clipboard-text-clock-outline`.
### Réglages
Assemblage de cartes autonomes, ordre : HeartRate → CadenceSensor → Map → HealthConnect (Android) → Profile → Goals → WeekPlan → ProgressionAuto → Notifications → Data → DataExport → StravaImport → Backup. Titre « Réglages », `paddingBottom 40`, `gap 16`.
### Sortie (`/sortie?type=`)
Keep-awake ; type → teinte, label, table MET, allure si course/marche. Phases `idle|active|paused|saving|save-failed`. `begin()` : permission notif best-effort → `gps.start()` (coarse → alerte « Position précise requise » ; denied → « Localisation refusée ») → `createSession` (échec → « Impossible de démarrer ») → buffers remis à zéro, chrono. Flush toutes les 20 s (et à la pause) : `takeUnflushed` → `attachSensors` (nearestSample FC + cadence) → `insertTrackPoints`, réentrance gardée. BLE : abonnement aux trames brutes + `pushDownsampled`. `pause/resume`. `finish()` → confirmation « Terminer la sortie ? » → `save()` : résultat `gps.stop()` figé (réessai sûr), `movingTimeSec` clampé, vitesse moyenne, calories, `summarizeHr/Cadence`, `finalizeSession` atomique, `finalizeSavedSession`, `router.replace(détail)` ; erreur → `save-failed` + alerte, séance récupérable. `discard()` : « Abandonner la sortie ? » → stop + `deleteSession` + retour. Retour matériel → `discard()`. Démontage → `gps.stop`.
UI : en-tête (`close` 26, icône 22 + label, espaceur) ; bloc chrono (« DURÉE » en couleur d'activité, `metricLg` 64/800 tabulaire, `maxFontSizeMultiplier 1.2`, `GpsStatusPill` : « GPS précis » ≤10 m success / « GPS ±N m » warning / « Recherche GPS… » / « GPS refusé » danger) ; carte de stats live (héros Vitesse ou Allure `speedometer`/`timer-outline` 44 pleine largeur, Distance, Cardio `heart-pulse` heart, puis compacts Vitesse max / Meilleure allure, Vitesse roue `bike-fast` (si capteur et pas allure), Cadence `rotate-right` (si capteur), Dénivelé + `elevation-rise`, Calories `fire` warning — calories live sur la vitesse **moyenne**) ; carte `RouteMap` live 220 dès ≥2 points sinon `MapPlaceholder` (`map-marker-path` + texte contextuel) ; barre de contrôle flottante (fond `backgroundElement`, bordure hairline, `Elevation.lg`, `paddingBottom insets+12`) : idle « Démarrer la sortie » (`play`, loading pendant `requesting`) ; save-failed « Abandonner » (secondary danger flex 1) + « Réessayer » (`refresh` flex 1.4) ; sinon « Pause »/« Reprendre » (flex 1) + « Terminer » (`flag-checkered`, flex 1.4).
### Muscu (`/muscu?template=&add=`)
Keep-awake. `Exercise {id, name, sets:[{reps, weightKg, done?}], target?, repUnit?, lastWeight?, howTo?, muscles?, icon?, imageKey?, difficulty?, bump?, bumpKind?}`. Hydratation : profil → refs ; repos `rest_seconds` clampé [15,600] sinon `goalSpec(goal).restSec` ; brouillon présent → restauration (ids régénérés, `watch.seed(elapsed)`, **départ en pause**) ; sinon `startedAt=now`, chrono, permission notif, notification live `muscu`, `?template=` → `loadTemplate` (remplace la liste, via `targetsForExercises`) ; `?add=<catalogId>` → ajout avec `lastWeightByExercise`. Persistance : `persistDraft()` à chaque changement de `[exercises, paused]` (ou `clearMuscuDraft` si vide) et à l'AppState non actif.
Interactions : cocher une série (`PressableScale` haptic success, cercle 26 rempli muscu + `check`) → **démarre le repos** ; `Stepper` reps (pas 1, min 1, suffixe reps/sec) et charge (pas 2.5, min 0, décimal, kg) avec saisie inline (virgule acceptée, arrondi 0.1) ; retirer une série (confirmation si cochée) ; retirer un exercice (toujours confirmation) ; chips ressenti facile/moyen/dur (re-tap désélectionne) ; ligne « Auto : +2,5 kg cette semaine » / « Allégé : … » si bump ; `information-outline` → `ExerciseInfoSheet` ; carte d'ajout : « Parcourir le catalogue » (modal plein écran `ExerciseCatalog`), champ libre + bouton `plus`, chips rapides (Développé couché, Squat, Soulevé de terre, Développé militaire, Rowing, Tractions, Curl biceps, Dips) ; sélecteur de programme seulement si liste vide (tuiles 2 colonnes) ; résumé Durée / Séries done/total / Cardio / Volume.
Sortie : `finish()` → « Terminer la séance ? » → `saveMuscuSession` (séries aplaties, difficulté dénormalisée), puis `clearMuscuDraft`, `finalizeSavedSession`, notification effacée, `replace(détail)`. `exitSession()` (X et retour matériel) : vide → effacer + retour ; sinon alerte 3 choix Continuer / **Mettre en pause** (brouillon, retour) / **Abandonner**. `RestTimer` au-dessus de la barre (Pause/Reprendre flex 1, Terminer flex 1.4).
### Détail de séance
Charge : session, points (GPS), séries (muscu), `sessionRecords`, `maxHr` profil ; rechargement après retype. En-tête natif : titre = activité, droite `share-variant` + `trash-can-outline` (danger). Corps : icône 54×54 teintée + label + `formatDateTime(startedAt, true)` ; `RecordsBanner` (fond `warning+'14'`, `trophy`, « Record personnel » / « Record {année} », ≤3 records « Meilleure {distance|dénivelé|durée|vitesse moyenne} de tous les temps / de {année} ») ; miniature `RouteMap` cliquable → carte plein écran (badge `arrow-expand`) ; carte de stats (« En mouvement » ou Séries + Exercices ou Durée ; « Temps total » si total − moving ≥ 60 s ; GPS : Distance, Vitesse/Allure moy., Vitesse max/Meilleure allure, Dénivelé +, Cadence moy./max ; FC moy. `heart-pulse`, FC max `heart`, Calories `fire`, Effort `speedometer` coloré) ; `ChartCard` × 3 si ≥2 points (Vitesse km/h couleur activité + moyenne pointillée ; Altitude m `textSecondary` ; Fréquence cardiaque bpm heart + moyenne ; X en km) ; `HrZonesCard` ; `MuscuBreakdown` (une carte par exercice, lien → fiche, pastille difficulté success/warning/danger 22 %, volume, lignes « n — reps × kg ») ; Notes ; `SessionTypeCard` (GPS) ; boutons « Exporter en GPX (Strava) » (GPS ≥2 points, secondary `cloud-upload-outline`), « Partager la séance » (secondary), « Supprimer la séance » (danger). `ShareCard` rendue hors écran et capturée en PNG ; fond MapLibre pré-rendu (360×200) si style configuré.
### Carte plein écran
`RouteMap interactive fill height=windowHeight`, bouton retour flottant 44 (`arrow-left`) à `insets.top+8 / insets.left+16`, vide « Aucun tracé à afficher. ».
### Progression
Au focus : `listMuscuExercises()`, `getAutoProgressionState()`. Carte « Changements de la semaine » si `state.week === isoWeekKey(now)` (`trending-up`, `changeSummaryLine`, lignes `arrow-up-bold` success / `arrow-down-bold` warning + `describeChange`). Label « Suivi des charges, exercice par exercice… ». Liste `ExerciseSummary` → fiche (`dumbbell` muscu, nom, « N séance(s) · dernière {date} », dernière charge, flèche selon `lastDifficulty`). Vide « Ta progression démarre ici » + « Démarrer une séance muscu ».
### Fiche exercice
`exerciseHistory(name)` ; guide via `exerciseByName` puis `catalogByName`. Titre = nom ; carte guide (`ExerciseIllustration` 156, pastilles muscles, « EXÉCUTION » + how-to 15/23) ; résumé Record / Actuel / Depuis le début (delta coloré) ; 1RM (« 1RM actuel » / « 1RM record », « Estimation Epley d'après la série la plus lourde de chaque séance. ») ; conseil (`arrow-up-bold`/`arrow-down-bold`/`equal`/`gesture-tap`, `adviceLabel`, « Dernière séance : {difficulté} ») ; « Charge max par séance » `BarChart` muscu 10 dernières (labels `D/M`) ; liste « Séances » (plus récente d'abord : « X kg × N reps », date, « ≈ N kg 1RM », séries, volume). Vide « Aucune donnée ».
### Catalogue (autonome)
`RecoProfile` depuis le profil ; `ExerciseCatalog addLabel="Ajouter à une séance" onPick → /muscu?add=id`.
### Poids
Liste virtualisée avec en-tête riche : « Nouvelle pesée » (`scale-bathroom`, champ décimal `maxLength 6`, suffixe kg, « Enregistrer » `check` → `parseWeightInput` (76,4/76.4, arrondi 0.1, rejet <20 ou >300 avec message danger) → `logBodyWeight`) ; métriques Actuel / 30 jours (delta vs pesée d'il y a 30 j) / Depuis le début (`+`/U+2212) ; « Évolution » `LineChart` accent si ≥2 ; journal en bloc continu (`backgroundElement`, séparateurs hairline, coins `Radius.lg` premier/dernier), lignes kg tabulaire, date, delta, `trash-can-outline` avec confirmation.
